# Financial Investment Analyzer

A React-based web application that helps investors analyze and select companies based on ROIC (Return on Invested Capital) and risk metrics.

## Features

- **Sector-based Filtering**: Browse companies by industry sector
- **ROIC-based Analysis**: Companies ranked by Return on Invested Capital
- **Risk Assessment**: Visual risk probability indicators
- **Investment Calculator**: Calculate optimal allocation based on investment amount
- **Interactive Charts**: Revenue, ROIC, and risk visualizations
- **Portfolio Optimization**: Smart recommendations based on user's risk tolerance
